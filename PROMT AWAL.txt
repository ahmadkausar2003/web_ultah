=========================================
📄 PRODUCT REQUIREMENTS DOCUMENT (PRD)
=========================================
- Nama Proyek: Birthday Web Quest
- Target Platform: Flutter Web (Responsive: Mobile & Desktop, tapi utamakan aspect ratio Mobile).
- Tema Visual: Cute, Bubbly, Pastel colors (Pink, Baby Blue, Mint).
- Tipografi: Package `google_fonts` (Nunito & Fredoka One).
- State Management: `provider` (untuk menyimpan nama teman yang dipilih, status audio, dan progress).
- Animasi & Efek: WAJIB menggunakan `flutter_animate` untuk transisi (slide, fade, bounce, shake) dan `confetti` untuk Layer 7.
- Audio: `audioplayers` untuk BGM (looping) dan SFX (Sound Effects) pada setiap tombol/interaksi.

--- Detail 7 Layer (Alur Berurutan) ---
1. GateScreen (Pemilihan Karakter): 2 Card tombol (Teman A & Teman B). Klik -> Simpan state -> Mainkan SFX -> Mulai BGM -> Pindah ke Layer 2.
2. MissionScreen (Ruang Misi): Gambar maskot menangis. Teks Typewriter: "Gawat [Nama Teman]! Kue ulang tahunmu dicuri!". Tombol "Mulai Misi" berdenyut.
3. BalloonScreen (Hutan Balon): Mini-game memecahkan 5 balon melayang (Stack & Positioned). Tap balon -> SFX Pop -> Balon hilang -> Counter naik. Jika 5, muncul tombol "Lanjut".
4. TriviaScreen (Jembatan Memori): 1 Pertanyaan trivia hardcode. 3 Pilihan. Salah -> Tombol Getar (Shake) & SFX Salah. Benar -> Tombol Hijau, SFX Benar, Lanjut.
5. BakingScreen (Dapur Ajaib): Ikon mangkuk & LinearProgressIndicator. Tombol "Kocok Cepat!". Spam klik tombol -> Progress naik 5% per klik, mangkuk bergetar. 100% -> Delay 1s -> Pindah layar.
6. DecorateScreen (Dekorasi): Base gambar kue. Tombol toggle untuk hiasan (Cokelat, Stroberi, Lilin) menggunakan Stack. Minimal 1 hiasan aktif untuk lanjut.
7. SurpriseScreen (Pesta Utama): Layar gelap 1 detik -> Terang! Confetti meledak. Teks "HAPPY BIRTHDAY [Nama Teman]". Carousel foto (ListView), Teks ucapan panjang, Tombol "Peluk Jauh" memunculkan partikel hati. BGM ganti ke lagu ultah.
